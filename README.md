# Suspect - Pass-the-Phone Party Game (Android)

**Suspect** is a premium offline pass-the-phone party game suite built natively for Android using **Kotlin** and **Jetpack Compose** with Material Design 3.

## Game Modes

### 1. Number Justify
- Every player receives a question and submits a numeric or short answer.
- One or more secret Impostors receive a slightly altered question.
- All answers are revealed together.
- Players discuss before the timer expires, then vote to catch the liar.

### 2. Impostor Word
- Players choose a word category (Food, Places, Animals, Activities, Objects, Jobs, Nature, or Random Mix).
- Pass the device around. Players hold the secret scroll to reveal their assigned word.
- Safe players get the majority word; Impostors get a related secret word.
- Players describe their words carefully without giving away the secret, then vote out the Impostors.

## Features
- **Offline Pass-the-Phone**: Play anywhere without an internet connection or separate devices.
- **Customizable Rules**: Adjustable discussion timer (30s – 300s) and impostor counts.
- **Over 400 Secret Content Pairs**: 200 question pairs and 200 word pairs across 8 categories.
- **Material Design 3 Dark Aesthetics**: Modern dark theme `#0F0F14` with electric purple and cyan accents, edge-to-edge support, custom adaptive launcher icon, and smooth Compose transitions.
